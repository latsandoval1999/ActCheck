# Real failures found and fixed, by agent

For the portfolio templates (Section 6 Testing results and Section 7 Failures found and corrections made).
Every entry is a failure that actually happened in ActCheck, how it was caught, and the rule or fix that now
prevents it. "Held" means a safeguard stopped the failure before it reached the reviewer; "Failed" means it
got through and was fixed afterwards. New failures are added here as they are found (most recent last in each table).

Sources: `docs/VERSION_LOG.md`, `docs/PROJECT_LOG.md`, `runs_archive/`, `logs/*.jsonl`, the test suite (`tests/`).

## 2026-11-18 — Review records that could outgrow one sheet cell (found while checking, no data lost)
- What was found: HB 2322 showed "Not yet started" after a restart. That was the reviewer's own reset (ticks removed so the site starts from a clean case), not a loss. While checking, a real risk turned up: a record could carry two large old outputs (diagnosis, redteam, about 32,000 characters) that were not excluded from the sheet copy, so a long review could pass the 50,000-character limit of one Google Sheet cell and its copy would fail silently. A stale HB 2322 file also shipped in the repo.
- Fix (precaution): the old outputs are no longer copied; long records are compressed (about 15 times smaller); restore reads the latest readable row and retries if the sheet does not answer; review files are no longer kept in the repo. Test added.
